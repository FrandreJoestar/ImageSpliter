# ImageSpliter

一款本地运行的 Windows 桌面图片分割工具：导入图片、拖动分割线、按任意角度旋转，选中需要的块后一次性导出为 PNG / JPEG / WebP，并在导出前实时预估压缩后的总体积。

所有处理都在本机完成，图片不会上传到任何服务器。

## 功能特性

### 图片库
- 支持导入单张图片或整个文件夹（递归一层自动扫描）
- 支持直接把文件 / 文件夹拖放到窗口中
- 支持格式：`jpg` `jpeg` `png` `webp` `bmp` `gif` `tif` `tiff` `heic` `heif`
- HEIC / HEIF 通过原生 libheif 解码，可直接预览与导出
- 自动去重，导入时汇总成功、重复与失败数量

### 分割与编辑
- 在图片上添加水平 / 竖直分割线，拖动即可实时调整位置，分割线标注像素坐标
- 网格化选择导出块，支持全选、反选、清空
- 旋转滑块范围 `-180° ~ 180°`，支持连续自由角度，也可直接输入精确数值
- 图片图层与辅助线图层分离渲染：旋转只作用于图片，参考线始终保持水平 / 垂直
- 提供 90° 快捷旋转与一键复位
- 画布支持缩放、平移与适应窗口，并限制在视图区域内不遮挡其他界面

### 导出
- 按当前旋转方向与选中块精确裁剪，所见即所得
- 输出格式：PNG（无损、支持透明）/ JPEG（有损、体积小）/ WebP（有损、体积更小）
- JPEG / WebP 可调节 1 - 100 的压缩质量
- **导出前实时预估压缩后总大小**：在导出页面醒目位置展示总大小，以及原始大小、图片数量与预计节省比例
- 预估基于原分辨率采样块真实编码，图片增删、格式切换、质量调整都会即时刷新
- 导出过程展示逐块进度，结果汇总成功、跳过与失败条目，可直接打开输出文件夹

### 界面与体验
- Material 3 标准配色方案，支持浅色 / 深色 / 跟随系统三种主题模式
- 主题选择持久化到本地，重启后自动恢复
- 全部界面颜色取自 `ColorScheme` 语义角色，明暗模式下均保持良好对比度
- 图片检查器默认收起，悬浮展示且点击外部自动收回

## 环境要求

- Windows 10 / 11
- Flutter 3.x（Dart SDK `^3.12.1`）
- Visual Studio 2022（含「使用 C++ 的桌面开发」工作负载）

## 快速开始

```bash
git clone <仓库地址>
cd imagespliter
flutter pub get
flutter run -d windows
```

构建发布版本：

```bash
flutter build windows --release
```

产物位于 `build\windows\x64\runner\Release\`。

## 使用流程

1. 点击「导入图片」或「导入文件夹」，也可以直接把文件拖进窗口
2. 在左侧图片库中选择要处理的图片
3. 在画布上添加水平 / 竖直分割线，拖动分割线调整切割位置
4. 用底部旋转滑块或数值输入调整图片角度（辅助线不受影响）
5. 在右侧「导出块」中勾选需要导出的块
6. 点击「导出项目」，选择输出目录与格式，确认预估总大小后开始导出

## 项目结构

```
lib/
├── main.dart                     # 应用入口、主题注入
├── app_theme.dart                # Material 3 主题与语义色板
├── controllers/
│   └── project_controller.dart   # 图片库、选中项与导入逻辑
├── models/
│   ├── image_document.dart       # 单图编辑状态（分割线、旋转、选中块）
│   └── export_settings.dart      # 导出参数与进度 / 结果模型
├── services/
│   ├── image_processor.dart      # 解码、旋转裁剪、HEIC 支持
│   ├── project_exporter.dart     # 批量裁剪与编码导出
│   ├── export_size_estimator.dart# 压缩体积预估
│   └── theme_preferences.dart    # 主题偏好持久化
└── ui/
    ├── home_page.dart            # 主界面与拖放
    └── widgets/                  # 图片库、画布、检查器、导出弹窗
```

关键实现说明：

- **旋转渲染**：图片图层与辅助线图层分别由独立的 `CustomPainter` 绘制，辅助线不读取旋转信息，因此始终正交。
- **导出几何**：任意角度的外接矩形由 `w' = w·|cos| + h·|sin|`、`h' = w·|sin| + h·|cos|` 计算，预览与导出共用同一套几何。
- **体积预估**：每张图解码一次，截取不超过 512px 的原始分辨率采样块，用目标格式与质量在独立 isolate 中真实编码，得到每像素字节数后按导出块像素数外推；采样块与编码结果均有缓存。
